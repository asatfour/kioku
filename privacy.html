プライバシーについて

「記憶」がどのデータをどこに置くか、どこへ送るかを、実装に即して書いています。
最終更新: 2026年8月6日

要点
このアプリにサーバはありません。アカウント登録も不要です。
読み込んだデッキと学習履歴はあなたの端末の中だけに保存され、こちらからは見えません。
ただし AI機能を使ったときだけ、そのカードの内容が選んだAI提供元へ送られます。

1. 保存されるもの・保存場所

データ保存場所外部へ送るか
読み込んだデッキ（問題・答え・画像）端末内（IndexedDB）送りません
学習履歴・記憶の状態端末内（IndexedDB）送りません
設定・AIのAPIキー端末内（localStorage）APIキーは選んだ提供元への認証にのみ使用
AIとのやりとりの記録端末内（IndexedDB）送りません

アプリを削除する、ブラウザの「閲覧データを削除」を実行する、設定の「全部消す」を押す — いずれの場合もこれらは消えます。復元手段はありません。 設定の「バックアップ」から .apkg として書き出しておいてください。

2. AI機能を使ったとき

「AIに聞く」を押すと、そのカードの問題文・正答・デッキ名・タグと、あなたが入力した質問が、 設定で選んだ提供元へブラウザから直接送られます。当方のサーバは経由しません。

設定送信先
Gemini（既定）Google（generativelanguage.googleapis.com）
ClaudeAnthropic（api.anthropic.com）
OpenAI互換設定した宛先
アプリ内では使わないClaude のサイトを新しいタブで開きます（内容がURLに載ります）

送られた内容が提供元でどう扱われるかは、各社の規約によります。 AI機能を使わなければ、カードの内容は端末から出ません。

3. アクセス記録

このアプリは GitHub Pages で配信しています。ページやファイルを読み込む際、 GitHub 社のサーバに一般的なアクセス記録（IPアドレス・日時・取得したファイル名など）が残ります。 これは配信元の仕組みによるもので、当方が取得・保存しているものではありません。

4. 集めていないもの

  • アクセス解析（Google Analytics 等）を入れていません
  • エラー収集サービスを入れていません
  • 広告・追跡用の Cookie を使っていません
  • アカウント・メールアドレス・氏名を取得しません

したがって、誰がどのデッキで何を学習しているかを、こちらが知る手段はありません。

5. 他人が作ったデッキを読み込むとき

.apkg には HTML が含まれます。悪意のあるデッキがカードに仕込んだコードで 端末内のデータ（APIキーなど）を持ち出せないよう、読み込んだカードは表示前に無害化しています （実行される要素・外部への通信を取り除きます）。 それでも、出所の分からないデッキの読み込みは避けてください。

6. 同梱しているソフトウェア

第三者のライブラリを同梱しています。著作権表示とライセンスは こちらをご覧ください。

7. 免責

個人が学習用に作ったものです。データの消失・学習結果について責任を負いかねます。 大切な学習履歴は必ず書き出して保管してください。
